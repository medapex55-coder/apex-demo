# Launch plan

Scope: **personal / learning**. There's no public launch, so these replica-launch steps were deliberately skipped:
- **Landing page:** none. The app opens straight into Study.
- **Pricing:** none. Free, local, no account. For reference only: the original's public tiers were $0 / $39 / $79 / $139 / $229 per month ([pokerlistings](https://www.pokerlistings.com/poker-tools/trackers/gto-wizard), read 2026-10-29).
- **Store listing:** none. Web only, so `listing.py` isn't needed.

If this ever goes public:
1. Run the "to run" trademark and domain checks in brand.md, and measure the original's brand colours into brand.json.
2. Build a landing page around angle #1 in fixes.md: "explains the why, free".
3. Collect 100+ real reviews first (fixes.md is thin).
4. Replace the heuristic strategies with real solver output, or keep the "demo strategies" label everywhere.
5. Never put the original's name in the name, copy, keywords or ads.
