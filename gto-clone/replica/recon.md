## Core loop

Pick a spot (format → preflop action line → board) and see the solver strategy for every hand on a 13×13 grid, then drill that spot in a trainer that grades each decision against the strategy.

## Flows

```
F01 Study a preflop spot
    S02 (default: UTG open) -> click position/action in ActionSequence -> S02 updated grid -> hover hand -> HandDetail
    happy path clicks: 2
    edge: action sequence that skips players (auto-fold), hand not in range (black), switching units

F02 Study a postflop spot
    S02 -> S03 pick line (BTN open, BB call) -> S04 pick flop (3 clicks) -> S02 flop strategy -> click action (e.g. check) -> next player's node
    happy path clicks: ~7
    edge: card already used, random flop, going back up the tree via breadcrumb

F03 Filter the grid
    S02 -> click hand category bar / action row -> grid dims non-matching -> CLEAR (P)
    happy path clicks: 2

F04 Compare ranges
    S02 -> tab 2 S05 -> pick equity bucket -> both grids filter
    happy path clicks: 2

F05 Drill a spot in the trainer
    S10 choose spot + mode (Spot) + difficulty -> Start -> S11 hero acts -> S12 grade -> next hand (auto)
    happy path clicks: 3 to first decision, 1 per hand after
    edge: timeout (auto fold/check), RNG mode, paused after mistake, free hand limit S18

F06 Play a full hand
    S10 mode=Full Hand -> S11 preflop decision -> S12 -> flop dealt -> decision -> ... -> hand over -> S14
    edge: hero folds early, opponent folds, all-in

F07 Review progress
    S15 -> S16 open session -> show hands -> S17 replay
    happy path clicks: 3
```

## Inferred data model

```
Spot / Solution  id, format (cash|mtt), players (6max), stack_bb, rake, sizing (simple|multi)
                 evidence: review (solution type, players), Study top bar
                 confidence: high

Node             id, solution_id, path (action line e.g. "UTG:r2.5,HJ:f,..."), street, board, active_player, pot, to_call
                 evidence: S02 infobox (pot, odds, active player), action sequence
                 confidence: high

NodeStrategy     node_id, hand (169 classes, or 1326 combos), freqs {action -> 0..1}, ev, eq, eqr, weight
                 evidence: S02 summary table columns (strategy, range weight, EV, EQ, EQR)
                 confidence: high

Action           code (fold|check|call|bet|raise|allin), size (bb or %pot)
                 evidence: actions table, bet unit toggle
                 confidence: high

User             id, email, plan, settings {theme, bet_units, …}
                 evidence: settings, plans
                 confidence: high

TrainerSession   id, user_id, config {spot, mode, difficulty, rng, speed, timebank}, started_at, hands, gtow_score, ev_loss_bb, mistakes
                 evidence: Measure Performance article
                 confidence: high

TrainerHand      id, session_id, hero_pos, hero_cards, board, actions[], ev_loss_bb, score
                 evidence: Practiced Hands page (sortable by EV loss, frequency difference)
                 confidence: medium

Decision         hand_id, node_path, chosen_action, gto_freqs, grade (best|correct|inaccuracy|wrong|blunder), ev_loss, rng_roll
                 evidence: move categories, feedback
                 confidence: medium (guess on storage granularity)

Drill            id, user_id, name, config
                 evidence: help "Manage Training Drills"
                 confidence: medium
```

Relationships: Solution 1-n Node, Node 1-169 NodeStrategy, User 1-n TrainerSession, TrainerSession 1-n TrainerHand, TrainerHand 1-n Decision, User 1-n Drill.

## Out of scope (cannot or should not be cloned)

- GTO Wizard's solution library and strategy numbers (their proprietary data). The clone generates its own demo strategies.
- GTO Wizard AI custom solving and nodelocking: a real-time solver is a research project of its own.
- Aggregate reports over 1,755 real solved flops: these need a real solver dataset.
- Analyze mode (hand-history parsing for every poker site) is deferred to a later phase.
- PokerArena (the player network and ratings), Table Wizard (desktop overlay), coaching and content.
- The name, logo, colour theme and copy: the clone gets its own brand.

## Size

Screens 18 (≈12 in scope for v1), flows 7, entities 9.
Hard parts:
1. A plausible strategy generator: preflop charts per position, plus postflop heuristics driven by hand-strength evaluation, kept consistent across the tree.
2. A hand evaluator with equity calculation (Monte Carlo) for the EV/EQ columns and trainer grading.
3. A dense, fast 13×13 grid with stacked frequency colors, hover detail and filters.
Size: **M** (a few weeks for the full scope; a working v1 of Study + Practice in a focused session).
